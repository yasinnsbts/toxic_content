# Toxic Content Classification

Учебный проект по дисциплине «Обработка естественного языка».

Цель проекта — разработать систему классификации голосовых сообщений
по типу содержимого.

Для проекта рассматривается датасет HateXplain.

## Датасет

HateXplain — англоязычный датасет сообщений из социальных сетей.

В датасете используются три класса:

- hatespeech
- offensive
- normal

Исходный датасет содержит 20 148 сообщений.
Каждое сообщение размечалось несколькими аннотаторами.

Для проекта планируется использовать текстовые данные HateXplain
и преобразовать их в аудио с помощью TTS (Text-to-Speech).

TTS — технология, которая автоматически превращает текст
в голосовую запись.

## Разведочный анализ

В ноутбуке `notebooks/hatexplain_eda.ipynb` выполнен первичный анализ датасета:

- изучена структура данных;
- проверено распределение классов;
- проанализировано согласие аннотаторов;
- изучена длина сообщений;
- проверены дубликаты;
- рассмотрены особенности источников Gab и Twitter;
- выполнена проверка данных перед дальнейшим использованием TTS.

После удаления записей, где не было большинства среди аннотаторов,
осталось 19 229 сообщений.

Распределение классов:

- normal — 7 814;
- hatespeech — 5 935;
- offensive — 5 480.

Медианная длина сообщения составляет 20 токенов.
Около 98% сообщений содержат не более 50 токенов.

Перед дальнейшим использованием потребуется очистить служебные элементы
вроде `<user>`, `<number>` и эмодзи, а также убрать небольшое количество
конфликтующих дубликатов.

Также был обнаружен заметный перекос классов между источниками
Gab и Twitter. При подготовке итоговой выборки это нужно будет учитывать
при формировании выборки.
