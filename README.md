# Toxic Content Classification

Учебный проект по дисциплине «Обработка естественного языка».

Цель проекта — исследовать классификацию токсичного содержания в голосовых сообщениях.

## Датасеты

Для проекта выбраны два текстовых датасета:

### HateXplain

Англоязычный датасет сообщений из Twitter и Gab.

Основные классы:

- `hatespeech`
- `offensive`
- `normal`

Исходный датасет содержит 20 148 сообщений. Каждое сообщение размечалось тремя аннотаторами.

Источник:

https://github.com/hate-alert/HateXplain

### Toxic Russian Comments

Русскоязычный датасет комментариев из социальной сети OK.ru.

Основные категории:

- `NORMAL`
- `INSULT`
- `THREAT`
- `OBSCENITY`

Датасет содержит 248 290 комментариев и имеет мультилейбл-разметку: одному сообщению может соответствовать несколько токсичных меток.

Источник:

https://www.kaggle.com/datasets/alexandersemiletov/toxic-russian-comments

## Подготовка аудиоданных

Оба исходных датасета являются текстовыми.

Для получения голосовых данных планируется использовать TTS (Text-to-Speech) — технологию автоматического преобразования текста в речь.

После подготовки данных планируется провести три эксперимента:

1. обучение и проверка модели на данных HateXplain;
2. обучение и проверка модели на Toxic Russian Comments;
3. объединение двух подготовленных датасетов и обучение общей модели.

## Разведочный анализ

Для HateXplain был проведён первичный анализ данных.

Ноутбук:

`notebooks/hatexplain_eda.ipynb`

В ходе анализа были проверены:

- структура данных;
- распределение классов;
- согласие аннотаторов;
- длина сообщений;
- дубликаты;
- различия между источниками Twitter и Gab;
- особенности подготовки текста для TTS.
